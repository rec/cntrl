# Courier Prime source fonts

Unmodified Courier Prime Regular and Bold TrueType fonts by the Courier Prime
Project Authors, designed by Alan Dague-Greene for Quote-Unquote Apps. These are
source assets for bitmap conversion; they do not add selectable firmware fonts
by themselves.

Downloaded on 2026-10-27 from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/courierprime).
The [upstream project](https://github.com/quoteunquoteapps/CourierPrime) maintains
the family.

Pinned Google Fonts revision: `e7db6ca603fd4862010383ff17ffd6cc4ffac1c0`.
Upstream files are under `ofl/courierprime/`; local filenames are unchanged.

# Orbitron source fonts

Unmodified Medium and Bold TrueType fonts by Matt McInerney, bundled for the
pedal display demo. These are source assets for bitmap conversion; they do not
add a selectable firmware font by themselves.

Upstream: <https://github.com/theleagueof/orbitron>
